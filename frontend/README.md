# MatchPulse AI frontend

React + TypeScript + Vite dashboard for a synthetic football sequence.

Run `npm ci`, then `npm run dev` and open <http://localhost:5173>. The dashboard starts at `evt-064` in Analyst/English mode. It works without FastAPI; the sidebar's optional **API connection** link opens the health check.

Features: source-coordinate SVG pitch, eight-event timeline, replay/pause/seek/speed controls, event search/type filtering, evidence and trust tabs, sequence-prefix statistics, Fan/Analyst modes, English/French, and expandable sample traces.

All 32 views are preloaded **examples**, not live agent execution. The sample corpus is generated by `backend/scripts/export_dashboard_samples.py` and checked with the public API types. Do not edit the generated file directly. REST processing integration follows in Task 7.

Checks: `npm run lint` and `npm run build`. No new runtime packages were added for this milestone. See [dashboard documentation](../docs/dashboard.md) for behavior and acceptance checks.

See the [root README](../README.md) for setup, environment variables, run commands, and verification steps.
